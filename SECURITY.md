# Security Policy

GimDiff runs `git` and `gh` on your machine and writes over image files, so a flaw in how
it builds commands or chooses what to write can matter.

## Reporting a vulnerability

Please report it privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(*Security ▸ Report a vulnerability* on the repository) rather than in a public issue.
Include the steps to reproduce it and what an attacker would gain.

Only the latest release is supported with fixes.
